# HOUSE QUIZ RALLY（プリンシパルホーム 22周年イベント）

QRコードを読みとってクイズに答え、正解するたびに家のパーツを選んで、5問で自分だけの家を完成させるスマホ用ゲームです。

## コーダーの方へ（公開するデータはここ）
- **`test/` フォルダの中身**（`index.html` と `assets/`）を、公開したい場所にそのまま置いてください。フォルダ名は `test` ですが、**本番用の中身**です。
- 置き方・確認してほしいこと・QRコードのしるしは、**`docs/公開メモ_コーダー向け.pdf`**（1ページ）に書いてあります。
- 公開するURLが決まったら、QRコードを作り直します（URLの後ろの `#…` のしるしは変わりません）。

## 中身
- `builder.html` … ゲーム本体のソース（ここを直す）
- `assets/` … 画像と音楽の元データ
- `tools/build_site.py` … 公開用フォルダを作る道具（`python3 tools/build_site.py 出力先`）。使っているファイルだけを集めて、`index.html` と `assets/` にします
- `tools/make_qr_sheet.py` … QRコード11枚のA4シートを作る道具
- `test/` … 公開用フォルダ（`build_site.py` で作ったもの。GitHub Pages で動作確認にも使っています）
- `docs/` … コーダー向けの公開メモ

## しくみ
- 答えた問題と選んだパーツは、スマホのブラウザの中（localStorage）に記録します。サーバーには何も送りません。
- 問題は `builder.html` の `BANK`（5種別 × 3問）から、種別ごとに1問ずつランダムに出します。
- 公開には、HTTPS で、URLの最後の `#…` が消えない場所に置く必要があります。
